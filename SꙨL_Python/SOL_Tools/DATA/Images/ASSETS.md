# Ressources graphiques

Les images utilisées par `NASA.py` et `SOL_Tools/Graph_tools.py` sont fournies dans `SꙨL_Python/SOL_Tools/DATA/Images/`.

| Fichier | Usage | Source et crédit |
|---|---|---|
| `Moon.jpg` | Texture de la Lune | [NASA Scientific Visualization Studio — CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/). Carte couleur LROC WAC, crédit NASA/GSFC SVS; données d’imagerie de l’Arizona State University. |
| `starmap_4k.jpg` | Fond étoilé | [NASA/GSFC Scientific Visualization Studio — Deep Star Maps](https://svs.gsfc.nasa.gov/3895/), visualisation Ernie Wright. Carte en coordonnées célestes, version 4K. |
| `World with Ice (4000x2000).jpg` | Texture de la Terre | NASA Blue Marble — land surface, ocean color, sea ice and clouds. Voir [NASA Earth Observatory](https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/). |
| `ECI Rotating Globe.png` | Globe schématique pour les vues ECI | Ressource graphique du projet. |

Les deux textures NASA SVS sont incluses avec leur résolution adaptée à l’affichage du simulateur. Les pages sources contiennent les crédits complets et les informations sur les données.
